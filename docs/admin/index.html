運営画面 実験用

開催設定・配置・公開対象を管理します。保存した設定はカタログの次回読み込み時に反映されます。

このブラウザーではログインを一時保存できません。再読み込み後は再ログインしてください。

運営としてログイン

出店者用の確認コードは使えません。運営として登録した宛先を指定してください。

開催設定・配置

空欄・期限終了後は出店者の編集を停止します。変更は設定保存後に有効です。

自動公開への変更で、既存の承認待ち出店も掲載されます。運営承認に戻すと、承認チェックのある出店だけが掲載されます。変更は「設定を保存」で確定します。

出店者と承認・配置
運営承認出店者作品・画像ブース番号

承認は出店単位です。承認後のプロフィール・作品・画像の編集に再承認は不要です。ブース番号が空なら「配置未定」です。

公開データ

初回の有効化・公開反映の復旧・シートを直接編集した後に使います。有効化後は保存時に自動更新します。未保存の入力は反映されません。
