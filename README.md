# 文芸同人誌即売会システム（実験用）

KLEAの既存サイト・KHBとは独立した試作です。本番の接続先・秘密値・実申込者情報を使いません。
確認コードは、Google側に登録したテスト担当者の宛先へ送信します。

## 現在の構成

- 公開カタログ・出店者編集・運営画面はGitHub Pages内で表示します。
- 出店者はメール確認後、本人のプロフィール・最大10作品・1作品3画像を保存できます。
- 運営は開催名・開催日・会場・編集期限・配置・公開対象を設定します。
- 公開対象の保存済み内容をGAS経由で都度取得します。更新ごとの運営承認・ZIP反映・pushは不要です。
- 公開カタログ本文を初回接続に同梱し、接続後の追加要求を減らします。画像は本文表示後に取得します。
- 画像は非公開Driveに置き、公開中の参照画像だけをGASから取得します。Drive ID・URLはカタログへ渡しません。
- JPEG・PNG・GIF・BMPをブラウザーで調整します。元画像20MB・6,000万画素まで、送信画像は長辺2,400px・1.5MBまで。GIFは先頭の静止画です。
- 新規画像は非公開で仮保存し、「保存して公開」で文章・作品・画像参照をまとめて確定します。
- 新規の一覧用サムネイルは長辺240px・30KBまで。旧400px・120KBの画像も利用できます。必要な位置の画像だけを取得し、拡大もHP内で表示します。
- 最初の代表画像を優先し、後続は最大3枚ずつ取得。ブラウザー内とGAS側のキャッシュで再表示・他の閲覧者の取得を軽くします。
- 画像登録後もプレビューを保持し、再読み込み時は本人用の小画像を自動表示します。
- 登録の変換・Drive保存を共通ロックの外で行い、最終確定時に権限・締切・競合を再検証します。
- 所有者検証・編集期限・更新競合・同一要求の再送・同じタブでのログイン復元を維持します。

「即時反映」は保存後の次回カタログ読込・再読み込みからです。既に開いている来場者画面への自動配信はありません。
未接続の初期状態は架空の2組・4作品のサンプルを表示します。接続設定後の通信失敗をサンプルへすり替えません。

## 配置と設定

公開URLは `https://kleaex.github.io/hf_test/`、出店者画面は `exhibitor/`、運営画面は `admin/` です。
利用者がGAS・Driveへ移動する必要はありません。通信先GAS URLは開発者ツールから確認できます。

**既存環境の更新は [SETUP.md](design/SETUP.md) の先頭「カタログの初回表示を短縮する」を使ってください。**
追加GASファイル、既存ファイルの更新、Script Properties、HPの接続設定、再デプロイをすべて記載しています。
今回追加するPerformance.gs・PublicCache.gsも配置が必要です。任意のHF_PERFORMANCE設定で、固定した処理名・時間・回数を確認できます。
ソース変更だけではGoogle側・GitHub Pagesへ反映されません。

日常設定はSheetsのEventSettingsを運営画面から更新します。Script Propertiesは接続先・秘密値・許可宛先・HPの許可origin等の環境設定です。
GASは非表示iframe内の通信処理に使い、HP側とorigin・iframeの所属・nonce・要求IDを照合します。
GAS内では各APIが引き続き本人・運営権限を検証します。

## ローカル確認

Node.jsで実行します。追加パッケージは不要です。

```text
node scripts/serve.mjs
node --test tests/*.test.mjs
```

`http://127.0.0.1:8080/` を開きます。`file://` は使いません。
`docs/connection.js` の `gasUrl` が空なら静的サンプルを表示します。
GitHub PagesはSettings → Pages → main /docs。コード更新の配信にはコミット・pushが必要です。

Googleサービスを代替したテストでは、認証・権限・競合・再送、公開対象の選別、仮保存→確定、画像取得、HP画面の処理、iframe通信の検証を行います。
実際のGoogleの画像変換、二重iframeの挙動、Google権限・割当、画面レイアウトは実環境で別途確認します。
旧GAS画面の接続・認証・編集権限、ログイン復元・画像機能はユーザー確認済みです。
今回のHP移行・自動反映はローカル検証済みですが、実GAS・Pagesでの確認は未実施です。

## 配置するもの

- `docs/`: HPのHTML/CSS/JS、公開用の接続先URL、サンプルJSON。秘密値は置きません。
- `gas/`: Google側へ手動配置するスクリプト・HTML・マニフェスト。
- `design/`: 設計・設定・受入試験。
- `tests/`: Googleを使わない検証。GAS・Pagesへ配置しません。
- `scripts/install-catalog.mjs`: 旧ZIP版の確認・取り込み用。自動反映の通常操作では使いません。

旧GAS編集画面・ZIP書き出しAPIは移行互換用に残しています。日常の入口はHP側に統一します。
旧画面のローカル模擬環境は `node tests/serve-experiment.mjs` で起動できます。HPの実通信の証明にはなりません。
ZIPの静的プレビューはGASに接続しません。接続中のHPでは、旧ZIPを取り込んでもライブ表示を切り戻せません。
申込受付・選考・入金・複数開催回の保持・前回からのコピーは未実装です。
編集期間終了後の変更・削除は原則不可。開催回をまたぐ再利用は将来、前回情報をコピーする方式で拡張します。
